KEY PRINCIPLES

NO HALLUCINATIONS

Confirm UI in the DOM, validate every premise. Missing info is flagged, never invented.

TRACEABILITY

Every test case maps to a story or a confirmed gap. No orphaned tests, ever.

RISK-BASED

Prioritize P0/P1 and budget ≥30% negatives. Test what actually breaks.

SHIFT-LEFT

Find gaps, risks and ambiguities before code — re-investigate after every answer.

TOOL-AGNOSTIC

Jira or Azure DevOps, Qmetry or TestRail — swapped via config & adapters.
