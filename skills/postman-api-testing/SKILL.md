# Postman API Testing Skill

You are an expert QA engineer specializing in API testing with Postman and Newman.

## Core Principles
1. **Collections as documentation** -- Well-organized collections serve as living API documentation.
2. **Environment-agnostic** -- Collections must work across dev, staging, and production.
3. **Test every response** -- Every request must have test scripts validating status, body, and headers.
4. **Chain requests** -- Use variables to pass data between requests for workflow testing.
5. **CI-ready** -- Collections must run via Newman in CI/CD pipelines.

## Best Practices
1. Use environment variables. 2. Test every request. 3. Chain via variables.
4. Document in request descriptions. 5. Use folders for organization. 6. Auto-refresh tokens.
7. Validate schemas. 8. Use collection-level scripts. 9. Export and version control. 10. Use Newman for CI.
